--------------------------------------------------------------------------------
1. 时区 / DATETIME 一致性
--------------------------------------------------------------------------------

  [INFO] 服务端时区
         @@time_zone=+08:00
         @@system_time_zone=CST
         NOW() − UTC_TIMESTAMP() = +8.0h

  [BLOCKER] ① 服务端默认值 vs 应用写入值
         server_filled = 2026-09-08 14:52:21.414 (服务端 +08:00)
         app_written   = 2026-09-08 06:52:21.437 (应用 UTC)
         偏差 = +8.00h

         原因：服务端 CURRENT_TIMESTAMP(3) 填入的是本地时间 (+08:00)，
         而应用侧通过 DSN timezone=Z 按 UTC 写入。同一张表中两套时间
         基准并存，查询 / 排序 / 定时任务均可能差 8 小时。

         受影响列 (3 表 7 列)：
           - dsh_session_persistence
           - exec_artifacts_datasets
           - workspace_quota_reservations

         建议修复方案：
           方案 A (推荐)：将服务端时区改为 UTC
             SET GLOBAL time_zone = '+00:00'
             或在 upsql 配置文件中设置 default_time_zone='+00:00'
           方案 B：去掉 DSN 中的 timezone=Z，使 JDBC/驱动层使用本地时区
             与 CURRENT_TIMESTAMP(3) 保持一致
           方案 C：应用侧不再依赖服务端默认值，所有时间列由应用按
             统一基准 (UTC) 显式写入

  [OK] ② DATETIME(3) 字面量往返
         写入 2026-01-02 03:04:05.678 → 读回 2026-01-02 03:04:05.678
         服务端不会在存取之间做隐式偏移。

--------------------------------------------------------------------------------
3. 排序规则混用
--------------------------------------------------------------------------------

  [WARN] ⑤ 排序规则混用
         @@collation_server    = utf8mb4_general_ci (服务端默认)
         @@collation_database  = utf8mb4_general_ci (库默认)
         显式表 (迁移写法)     = utf8mb4_unicode_ci
         漏写 COLLATE 的新表   = utf8mb4_general_ci   ← 继承服务端默认

         跨表 JOIN 比较结果：报错 1267
           Illegal mix of collations (utf8mb4_unicode_ci,IMPLICIT)
           and (utf8mb4_general_ci,IMPLICIT)

         影响：若新增迁移漏写 COLLATE，跨表比较 / JOIN / UNION 会在运行时
         抛出 1267 错误。现有 22 个迁移均已显式声明 utf8mb4_unicode_ci，
         不受影响。

  [WARN] ⑥ 需要卫生测试兜住
         建议：在 tests/ 增加一条断言，验证新建表的排序规则是否为
         utf8mb4_unicode_ci，防止后续新增迁移遗漏。

  建议修复方案：
     方案 A：将服务端默认排序规则改为 utf8mb4_unicode_ci
       SET GLOBAL collation_server = 'utf8mb4_unicode_ci'
     方案 B：在迁移模板 / codegen 中强制加上 COLLATE 子句，配合卫生测试兜底
